# PFIN-7 — Categorize expenses with predefined and custom categories

- **Epic:** [PFIN-1 — Expense Tracking](./_epic-PFIN-1.md)
- **Status:** Done ✅
- **Priority:** Medium

## Description

As a user, I want to assign a category to each expense so that I can organize, filter, and analyze my spending by category.

## Acceptance Criteria

- **AC1:** Given I am adding or editing an expense, when I click the category dropdown, then I see a list of predefined categories (Food, Transport, Utilities, Entertainment, Shopping, Healthcare, Education, Rent, Salary, Other)
- **AC2:** Given the predefined categories are insufficient, when I type a new category name, then it is created and available for future use
- **AC3:** Given I have expenses with categories, when I view the expense list, then I can filter by category
- **AC4:** Given I edit an expense, when I change the category, then the expense is reassigned to the new category
- **AC5:** Given a category has no expenses, when I manage categories, then I can delete that category
