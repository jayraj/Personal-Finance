# PFIN-1 — Epic: Expense Tracking

**Description:** Log, categorize, and manage daily expenses

As a user, I want to log, categorize, and manage my daily expenses so that I can maintain an accurate and organized record of my spending.

## Key Features

- Add expenses with amount, category, date, notes
- Categorize spending (Food, Transport, Utilities, Entertainment, Shopping, etc.)
- View, edit, and delete expense entries
- Attach receipt images

## Acceptance Criteria

- Users can create an expense with amount (required), category (required), date (defaults to today), and notes (optional)
- Users can view all expenses in a sortable, filterable list grouped by date
- Users can edit any field on an existing expense
- Users can delete an expense with a confirmation prompt
- Users can attach one or more receipt images per expense (JPG/PNG/PDF, max 5MB each)
- Custom categories can be created and managed
- Expense list supports search by category, date range, and amount
