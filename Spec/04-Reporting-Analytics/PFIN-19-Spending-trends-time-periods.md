# PFIN-19 — Spending trends over selectable time periods (7d, 30d, 12m)

- **Epic:** [PFIN-4 — Reporting & Analytics](./_epic-PFIN-4.md)
- **Status:** To Do
- **Priority:** Medium

## Description

As a user, I want to view spending trends over different time periods so that I can identify patterns and seasonal changes in my spending behavior.

## Acceptance Criteria

- **AC1:** Given I am on the Trends page, when I select "7 Days", then a line chart shows daily spending for the last 7 days
- **AC2:** Given I select "30 Days", then a line chart shows daily spending for the last 30 days with a 7-day moving average overlay
- **AC3:** Given I select "12 Months", then a bar chart shows monthly totals for the last 12 months
- **AC4:** Given I hover/tap a data point on any chart, then I see the exact date and amount
- **AC5:** Given the trends data is available, when I view the chart, then I can toggle between total spending and per-category views
