# PFIN-4 — Epic: Reporting & Analytics

**Description:** Visual dashboards and expense insights

As a user, I want to visualize my spending patterns and gain actionable insights so that I can make informed financial decisions.

## Key Features

- Monthly spending dashboard by category
- Spending trends over time
- Export data as CSV/PDF
- Month-over-month comparison

## Acceptance Criteria

- Dashboard displays a pie chart breaking down spending by category for the current month
- Bar/line chart shows spending trends over selectable periods (7 days, 30 days, 12 months)
- Users can export all expense data as CSV (machine-readable) and PDF (formatted report)
- Month-over-month comparison view shows side-by-side spending, highlighting increases/decreases
- Dashboard includes key metrics: total spent, average daily spend, top category, remaining budget
- All charts are interactive (hover for details, click to drill down)
